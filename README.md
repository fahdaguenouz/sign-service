# Sign Service

Blockchain document verification service using Ethereum.

## Features

- Connect MetaMask
- Upload document
- Generate SHA256 hash
- Sign hash
- Publish hash on blockchain
- Verify document
- Retrieve uploaded document (Bonus)

## Requirements

NodeJS
MetaMask
Hardhat

## Install

npm install

## Start local blockchain

npx hardhat node

## Deploy contract

npm run deploy

## Start server

npm run serve

Visit

http://localhost:3000

Connect MetaMask to

RPC:
http://127.0.0.1:8545

Import one of the Hardhat accounts.
